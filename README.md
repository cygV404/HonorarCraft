# HonorarCraft v1.2.1

Ein modernes Desktop-Tool zur Honorarabrechnung und Rechnungsverwaltung, entwickelt mit **Compose Multiplatform** und **Kotlin**.

## 🚀 Features
* **Plattformübergreifend:** Verfügbar für Linux, Windows und macOS.
* **Intelligente Erfassung:** Schnelle Eingabe und Speicherung von Stunden, Datum und Fächern.
* **Automatisierter PDF-Export:** Erstellt professionelle Rechnungen mit einem Klick.
* **Rechnungs-Management:** Automatische Inkrementierung der Rechnungsnummer nach Erstellung.
* **Lokale Datenspeicherung:** Alle Daten bleiben sicher auf deinem Rechner.
* **Security:** Kritische Daten (IBAN, Steuernummer, BIC) werden lokal verschlüsselt gespeichert.

## 🛠 Tech-Stack
* **Sprache:** [Kotlin](https://kotlinlang.org/)
* **UI-Framework:** [Compose Multiplatform](https://www.jetbrains.com/lp/compose-multiplatform/)
* **Build-System:** Gradle (Kotlin DSL)
* **Zielplattform:** Desktop (JVM)


#### 📦 Installation & Download
Für Endnutzer stehen vorkompilierte Installationspakete zur Verfügung. Lade einfach die passende Datei für dein System aus den **Releases/Assets** auf der rechten Seite herunter:

* **`.deb`**: Für Linux-Systeme (Getestet auf Mint/Ubuntu).
* **`.msi`**: Für Windows (Getestet auf Windows 10/11).
* **`.dmg`**: Für macOS (ungetestet).
